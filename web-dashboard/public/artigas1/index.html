Estación Artigas-1

La primera estación logística de Uruguay, en órbita. Flotá por el almacén, la recepción de carga, el taller y la Cúpula, con el Río de la Plata abajo. Las escotillas se abren solas cuando te acercás.

Estás en gravedad cero: el cuerpo conserva el impulso y las paredes son sólidas.
Compu: arrastrá para mirar, WASD para impulsarte, Q/E para bajar y subir, Espacio para frenar.
Quest: tocá «Enter VR». Cerrá la mano (grip) sobre una baranda o una pared y tirá para impulsarte. Stick izquierdo: propulsor. Stick derecho: girar de a 30° y subir o bajar. Gatillo: frenar. A/B: cambiar de módulo.
